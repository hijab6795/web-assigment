## 📌 Project Description

Hijab's Café is a responsive HTML and CSS and JavaScript powered café website. It offers a nice online café experience with the option to check out the café menu, special offers and opening times, calculate the amount of their order and send feedback using a contact form.

## 🛠️ Technologies Used

- **JavaScript:** Implements some interactive features on the website.- **MySQL:** Stores the website's content.
-Styling, layout, colors, responsive design, dark mode are all achieved via CSS3.
JavaScript is a language that is used to add interactive features and functionality.

## ✨ Features

- **Home Section:** Welcome message; if there is a live café, the status message will be displayed.
Introductory text for the Café is provided, accompanied by Read More and Read Less buttons.
Menu Section: Lists out the menu items, categories and prices of the café.
Use Menu Filter to filter out menu items by Drinks and Pastries.
Order Calculator: Automatically add up the price of items on the menu.
SpecialOffers: Displays the special offers of the café.
- **Opening Hours:** Indicates the times the café is open every day.
Dark/Light Mode: Toggle dark/light themes.
Contact & Booking Form: Name, e-mail address, date of booking, number of guests and seating preference will be filled.
- Discount Options: Student discount requests and eligibility for senior discount.
- **Feedback Form**: Checks user input, and outputs a message confirming it.
- Character Counter: Indicate the number of characters remaining in the special notes field.
- Responsive Design – works on desktop and mobile screens.
